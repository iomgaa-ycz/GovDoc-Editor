# 格式规范性 (workpaper-format-compliance)

## 评判标准
检查生成的 docx 工作底稿：
1. 是否遵循 workpaper.docx 模板的结构（章节标题、表格布局）
2. 占位符是否都被实际内容替换（无 {{ }} 残留）
3. 字段是否完整（项目名、文书路径、发现列表、摘要、日期）
4. 文档是否可正常打开且排版合理

## 评分规则
- 1.0：完全遵循模板，无占位符残留，排版合理
- 0.7-0.9：基本遵循，个别格式问题
- 0.4-0.6：多处格式问题或占位符残留
- 0.0-0.3：文档损坏或严重不符合模板

## 判定阈值
score >= 0.7 → passed
