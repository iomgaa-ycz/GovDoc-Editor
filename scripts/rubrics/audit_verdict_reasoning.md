# 判定推理自洽性 (audit-verdict-reasoning)

## 评判标准
逐个检查每个 GovFinding 的 verdict 与 rationale 之间的逻辑：
1. verdict（合规/不合规/存疑）与 rationale 描述的分析是否一致
2. 证据是否充分支撑结论（不合规需有明确违规证据，存疑需说明不确定原因）
3. 是否存在矛盾（如 rationale 说"未发现问题"但 verdict 判"不合规"）

## 评分规则
- 1.0：全部判定逻辑自洽，证据充分支撑结论
- 0.7-0.9：大部分自洽，个别推理链稍弱
- 0.4-0.6：存在明显矛盾
- 0.0-0.3：大量矛盾，结论与推理脱节

## 判定阈值
score >= 0.7 → passed
