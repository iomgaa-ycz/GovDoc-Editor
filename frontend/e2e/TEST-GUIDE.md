## 启动
# 1. 进入环境
conda activate govdoc-auditor-v3

# 2. 启动后端
uvicorn govdoc.api.main:app --host 0.0.0.0 --port 8000

# 3. 启动前端
cd frontend && npx vite --host 0.0.0.0 --port 5173

# 4. 启动测试（首次运行自动生成 fixture 到 e2e/.test-data/，无需手动准备文件）
bash frontend/e2e/run-tests.sh

## 阶段三：审核点库建设

> 用户通过导入或 AI 提取的方式准备审核标准

### T3.1 审核点库页骨架 🤖👤

**步骤**：
1. 点击侧边栏"审核点库"

**预期结果**：
- [ ] 页面标题"审核点库"
- [ ] "新建库"按钮
- [ ] "上传"按钮（下拉菜单含"AI 提取"和"导入审查点表格"）
- [ ] 左侧侧边栏：含"全部审核点"、"未分类"
- [ ] 搜索框（placeholder："搜索审查要点..."）
- [ ] "全部分类"分类筛选 pill
- [ ] 表头含 5 列：审查要点、分类、严重程度、状态、操作
- [ ] 全选 checkbox

### T3.2 导入 XLS 审核点 🤖👤

**前置**：准备审核点表格文件（`.xls` 或 `.xlsx`）。自动化使用运行时生成的 `e2e/.test-data/E2E测试审核点.xlsx`

**步骤**：
1. 点击"上传" → 选择"导入审查点表格"
2. 上传 XLS 文件
3. 点击"解析预览" → 等待预览数据
4. 点击"确认入库" → 等待导入完成
5. 点击"返回列表"

**预期结果**：
- [ ] 预览显示 4 项统计：新增、复用、重复、跳过
- [ ] "确认入库"后出现成功提示
- [ ] 返回列表后表格有新行
- [ ] 新行的分类 badge 和严重程度 badge 正确

### T3.3 导入后仪表盘"审核要点"数更新 👤

> 跨页面验证：导入操作应立即反映在仪表盘指标中

**步骤**：
1. 切到仪表盘，记录"审核要点"当前值 N
2. 切回审核点库 → 导入一个新的 XLS 文件（假设新增 K 个）
3. 回到仪表盘（刷新页面）

**预期结果**：
- [ ] "审核要点"新值 ≥ N + 新增数（减去重复跳过的）
- [ ] 如果不变 → 说明仪表盘数据未实时刷新，是一个 BUG

### T3.4 搜索审核点 🤖👤

**前置**：T3.2 已完成，列表中有数据

**步骤**：
1. 记录当前列表行数 N
2. 搜索第一行标题的前 4 个字符
3. 清空搜索框

**预期结果**：
- [ ] 搜索后行数 < N，显示的行都包含关键词
- [ ] 清空后恢复到 N 行

### T3.5 分类筛选 🤖👤

**步骤**：

### T3.11 库成员变化后已创建的审核任务不受影响 👤

> 跨页面验证：从库中移出审核点不会影响已有审核任务的结果

**步骤**：
1. 如果已有用该库创建的审核任务：
   - 从库中移出一个审核点
   - 切到 AI 审查 → 进入该任务详情页
   - 验证该审核点的审查结果仍然存在（finding 不丢失）
   - 该点在审核点网格中仍可见，状态仍为"已完成"
2. 库的 checkpoint_count 应已减少

**预期结果**：
- [ ] 审核结果不受库成员变化影响
- [ ] 库的数量正确更新

### T3.12 删除审核点库 🤖

**步骤**：

- [ ] 库从侧边栏消失
- [ ] 自动切回"全部审核点"视图
- [ ] 库内的审核点本身不被删除

### T3.13 删除库后审核点仍可用于新建审查 👤

> 跨页面验证：删除库不影响审核点本身

**步骤**：
1. 切到 AI 审查 → 打开新建审查抽屉
2. 查看"按审核点库"下拉框 → 已删除的库不再出现

**预期结果**：
- [ ] 已删除的库不出现在下拉框中

- [ ] 编辑后标题立即更新

自动化测试的数据文件由 `generate-test-data.py` 在首次运行 `run-tests.sh` 时自动生成到 `frontend/e2e/.test-data/`，无需手动准备：

|------|------|------|------|---------|

| `E2E测试审核点.xlsx` | XLSX | ~5KB | T3.2 导入 | openpyxl（含标准表头） |
| `E2E测试法规指引.md` | MD | ~260B | T3.20 AI 提取 | 纯文本 |
| `E2E测试法规指引.doc` | 假 DOC | ~25B | T3.21 UI 选择测试 | 占位文件 |

> **注意**：生成文件为最小合法格式，仅验证 UI 交互流程。真实大文件的转换质量、AI 提取深度等由后端单元/集成测试覆盖。
